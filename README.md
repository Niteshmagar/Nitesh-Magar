# GitHub Pages site
Upload all files and the `assets` folder to the root of your GitHub Pages repository. In Settings > Pages choose Deploy from a branch, main, /(root). Set custom domain `niteshranamagar.com.np` only if DNS is configured for GitHub Pages.

This is a static reconstruction of the Blogger Sora SEO 2 appearance, not the original Blogger runtime. Blog posts were extracted from Google Takeout. Profile picture and social links/video IDs should be verified and updated. New Blogger posts do not automatically sync.

# Official Nitesh Rana Magar — GitHub Pages

Static site generated from the supplied Sora SEO 2 Blogger theme and the **OfficialNiteshRanaMagar** Blogger Takeout feed. Layout is a Sora SEO 2-inspired recreation, **not an exact port** of Blogger widgets.

## Deploy

1. Extract the ZIP on your Mac.
2. Open your GitHub repository and upload **the contents of this folder**, not the ZIP alone. `index.html` must be at repository root.
3. Go to Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save.
4. Check the GitHub Pages URL first. For a custom domain, configure it in Settings → Pages and confirm the DNS records match GitHub's documentation. Do not switch your live domain until you have tested the site.

## Important

- The supplied Takeout has **3 LIVE posts** for this blog. Drafts and trashed posts are excluded.
- Original Blogger post paths are retained where available, but old Blogger URLs with other query parameters, feeds, and widgets may not work.
- Post images currently use their existing remote Blogger URLs. The `img/` directory also includes local assets from the Takeout BlogPathway album; not all are necessarily related to this blog.
- This is a static site: editing Blogger will **not** automatically update GitHub Pages. Comments, Blogger search, ads, and other dynamic Blogger widgets are not migrated.
- Inspect every page, link and image before switching the domain. The source theme license/attribution must still be respected.
